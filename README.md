# 🎬 CGV 광교 오디세이 IMAX 알림 봇

CGV 광교에서 **오디세이 IMAX 상영이 새로 열리면** Teams로 알려주는 자동 로봇이에요.
컴퓨터를 꺼놔도 인터넷에서 5분마다 알아서 확인해줍니다.

---

## 🧠 이 로봇이 일하는 방식 (그림으로 이해하기)

```
   ⏰ 5분마다              👀 CGV 페이지를 열어봄
   자동으로 깨어남    →    "오디세이 IMAX 회차가 뭐 있지?"
                                    ↓
                         🧠 수첩(state.json)과 비교
                         "어제는 12개였는데 지금 15개네?"
                                    ↓
                         🗣️ 늘어났으면 Teams로 알림!
                            (안 늘어났으면 조용히 다시 잠)
```

---

## 📋 설치하기 (한 번만 하면 끝, 약 15분)

### 1단계. GitHub 계정 만들기

1. https://github.com 에 들어가요
2. 오른쪽 위 **Sign up** 을 눌러 계정을 만들어요 (이메일, 비밀번호만 있으면 돼요)
3. 이미 계정이 있으면 **Sign in** 으로 로그인해요

> 💡 GitHub은 "프로그램을 올려두면 대신 실행해주는 창고" 같은 곳이에요. 무료예요.

### 2단계. 창고(저장소) 만들기

1. 로그인 후 오른쪽 위 **`+`** → **New repository** 클릭
2. **Repository name** 칸에 `cgv-imax-alarm` 입력
3. 아래에서 **Public** 을 선택해요 ← ⚠️ 중요! (Public이어야 무료로 무제한 실행돼요)
4. 맨 아래 **Create repository** 클릭

> 🔒 "Public이면 남이 보는데 괜찮아?" → 프로그램 코드만 보여요.
> Teams 주소 같은 비밀은 3단계에서 **금고**에 따로 넣기 때문에 아무도 못 봐요.

### 3단계. 파일 4개 올리기

1. 방금 만든 창고 화면에서 **uploading an existing file** 링크를 클릭
   (안 보이면 **Add file** → **Upload files**)
2. 제가 드린 파일들을 이 화면에 **끌어다 놓기(드래그)** 해요
   - `check.py`
   - `state.json`
   - `.gitignore`
   - `watch.yml` ← 이건 잠깐, 아래를 보세요 👇
3. `watch.yml` 은 **폴더 안에 들어가야 해요.** 이렇게 하세요:
   - **Add file** → **Create new file** 클릭
   - 파일 이름 칸에 정확히 이렇게 입력: `.github/workflows/watch.yml`
     (`/` 를 치면 폴더가 자동으로 만들어져요)
   - 아래 넓은 칸에 `watch.yml` 내용을 **복사해서 붙여넣기**
4. 초록색 **Commit changes** 버튼을 눌러 저장해요

### 4단계. 비밀 금고에 Teams 주소 넣기

1. 창고 위쪽 메뉴에서 **Settings**(⚙️) 클릭
2. 왼쪽 메뉴에서 **Secrets and variables** → **Actions** 클릭
3. 초록색 **New repository secret** 버튼 클릭
4. 이렇게 입력해요:
   - **Name**: `TEAMS_WEBHOOK_URL`
   - **Secret**: (Power Automate에서 복사한 웹후크 주소 붙여넣기)
5. **Add secret** 클릭

### 5단계. (선택) 설정 바꾸기

기본값이 이미 **CGV 광교 · 오디세이 · IMAX** 로 맞춰져 있어요.
그래서 이 단계는 **건너뛰어도 됩니다.** 나중에 다른 영화나 극장으로 바꾸고 싶을 때만 하면 돼요.

1. 같은 화면에서 위쪽 **Variables** 탭 클릭 (Secrets 옆)
2. **New repository variable** 클릭
3. 바꾸고 싶은 항목을 넣어요 (아래 표 참고)

| Name | 뜻 | 기본값 |
|---|---|---|
| `MOVIE_KEYWORD` | 찾을 영화 이름 | `오디세이` |
| `THEATER_KEYWORD` | 찾을 극장 | `광교` |
| `SCREEN_KEYWORD` | 찾을 상영관 종류 | `IMAX` |
| `CGV_URL` | 예매 페이지 주소 | `https://cgv.co.kr/cnm/movieBook/movie` |

### 6단계. 테스트하기

1. 창고 위쪽 메뉴에서 **Actions** 클릭
2. "workflows aren't being run" 같은 안내가 나오면 **I understand my workflows, go ahead and enable them** 클릭
3. 왼쪽에서 **CGV 광교 오디세이 IMAX 감시** 클릭
4. 오른쪽 **Run workflow** → 초록 **Run workflow** 버튼 클릭
5. 1~2분 기다린 뒤 새로고침 → 실행 기록을 클릭하면 로그가 보여요

**로그에서 이걸 확인하세요:**

```
2) 영화 '오디세이' 고르기
  ✔ '오디세이' 클릭 성공
4) 극장 '광교' 고르기
  ✔ '광교' 클릭 성공
   2026-08-22 → IMAX 5회차 ['08:00', '11:25', '14:50', '18:15', '21:40']
   ...
이번에 찾은 총 회차: 42건
```

- 이렇게 회차 시간이 줄줄이 나오면 ✅ **성공**
- `✖ '광교' 을(를) 누르지 못했어요` 가 나오면 → 클릭 방법을 손봐야 해요.
  이때는 실행 화면 아래쪽 **Artifacts** 의 `debug` 를 내려받아 저한테 보내주세요.
  로봇이 본 화면 캡처가 들어있어서 바로 고칠 수 있어요.

> 첫 실행은 **알림을 보내지 않아요.** 지금 상태를 '기준'으로 수첩에 적어두기만 해요.
> 두 번째 실행부터 새 회차가 생기면 Teams로 알림이 갑니다.

## ❓ 자주 생기는 문제

| 증상 | 이유 | 해결 |
|---|---|---|
| `⚠️ 화면에 '오디세이' 글자가 없어요` | CGV 주소가 상영시간표 화면이 아님 | 5단계의 `CGV_URL` 을 다시 복사해서 넣기 |
| 알림이 하나도 안 옴 | 아직 새 회차가 안 열림 (정상) | 기다리기 |
| 알림이 너무 자주 옴 | 광고/추천 영역까지 읽어서 오탐 | 알려주세요, 읽는 범위를 좁혀드릴게요 |
| Teams에 아무것도 안 옴 | 웹후크 주소가 틀림 | 4단계 금고의 주소 다시 확인 |
| 60일간 아무것도 안 하면 멈춤 | GitHub 규칙 | Actions에서 한 번 수동 실행하면 다시 살아나요 |

## 🔧 설정 바꾸고 싶을 때

**Settings → Secrets and variables → Actions → Variables** 에서 바꿀 수 있어요.

| 이름 | 뜻 | 기본값 |
|---|---|---|
| `CGV_URL` | 지켜볼 CGV 페이지 주소 | (필수 입력) |
| `MOVIE_KEYWORD` | 찾을 영화 이름 | `오디세이` |
| `SCREEN_KEYWORD` | 찾을 상영관 종류 | `IMAX` |
| `THEATER_NAME` | 알림에 표시될 극장 이름 | `CGV 광교` |

확인 주기를 바꾸려면 `.github/workflows/watch.yml` 의 `cron: '*/5 * * * *'` 에서
`*/5`(5분) 를 `*/15`(15분) 처럼 고치면 돼요.
